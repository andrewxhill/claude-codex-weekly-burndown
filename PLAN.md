# Weekly burn plan

This copy is a format example. It ships in the public repo and stays empty.

Your real queue lives wherever setup put it, recorded in `~/.config/weekly-burn/plan-path`. Setup defaults that path to a private directory outside this repo, because `add-job-to-burn-plan` fires during work in other repos and a job brief can name a client, an unreleased feature, or an internal system. None of that belongs in a public commit.

`docs/plan-format.md` has the row shape and the rules. Nothing here duplicates it, so that there is exactly one place to look and no example row an agent could mistake for real work.

Both headings below are load-bearing. The burner matches on them, `add-job-to-burn-plan` inserts under the first one, and the burner prepends under the second. Keep the wording as it is.
